# «Текст → 3D-модель» — рабочий документ и история переписки

Документ, чтобы в любой момент вернуться к проекту: что это, как устроено, где что лежит,
какие решения приняты и что осталось открытым. Ведётся вместе с кодом.

- **Приложение (прод):** https://alexey8080-create-3d-print-45dc.twc1.net
- **Репозиторий:** `alexey8080-create/3d-print`, ветка `main`, файлы: `index.html`, `README.md`.
- **Timeweb app:** id **248763** (`text-to-3d`), `frontend` / `static-nobuild`, preset `2801`
  (1 ₽, pay-per-request, ru-3), `index_dir` пустой (раздаёт корень), **автодеплой из `main`**.
- **Начато:** 4 сентября 2026.

---

## 1. Что это

Веб-приложение: пишешь текстовое описание объекта → ИИ **Meshy** генерирует 3D-модель →
её можно крутить со всех сторон во вьюере (Three.js) → скачать **STL** для 3D-печати (и GLB).
Личный проект пользователя. Всё в одном самодостаточном `index.html`, без сборки.

## 2. История переписки и решений (по порядку)

1. Начали с вопроса «можешь ли создать файл 3D-модели для печати» → да (STL через
   скрипт). Затем — «сделай приложение, где по описанию генерируется модель и её можно
   покрутить».
2. Обсудили развилку: **параметрический генератор** (офлайн, ограниченные формы) против
   **настоящего ИИ text-to-3D** (любые формы, нужен внешний сервис). Пользователь выбрал
   **настоящий ИИ** + экспорт STL.
3. Выбрали сервис **Meshy** (удобный экспорт в STL, image/text-to-3D). Приложение написано,
   но не сразу выложено — на «стоп».
4. Пользователь создал репозиторий `alexey8080-create/3d-print` и дал доступ токеном.
   Токен сперва был без права записи (`Contents`), после исправления прав — push прошёл.
5. Создали **отдельное Timeweb-приложение** (248763), привязали к репозиторию,
   настроили автодеплой из `main`. Прод поднялся (DNS технического домена — с задержкой).
6. Разобрали, **что такое Meshy** и **как получить API-ключ**: API только на платном плане
   **Pro ($20/мес)**, бесплатный план API не даёт.
7. Проверили **доступ из РФ**: сайт meshy.ai открывается **без VPN**, IP не блокируется.
   Барьер один — **оплата** (карта РФ для Stripe обычно не проходит, нужна зарубежная).
8. Уточнили: **Nano Banana Pro / Gemini не подходит** — это генератор 2D-картинок, а не 3D.
   Обход CORS (если понадобится) — это прокси, к ИИ отношения не имеет.
9. Обсудили промптинг для Meshy (один объект, английский, форма/стиль, под печать).
10. Добавили **конструктор промпта** + кнопку **«→ Перенести в описание»** и передачу
    `negative_prompt` в Meshy.

## 3. Как устроено (архитектура)

- **Генерация:** запрос из браузера в `POST https://api.meshy.ai/openapi/v2/text-to-3d`
  (режим `preview` — геометрия без текстур, для печати то что надо), затем опрос статуса
  `GET .../text-to-3d/{id}` до `SUCCEEDED`, забираем `model_urls.glb`.
- **Ключ Meshy** вводится на странице, хранится в `localStorage`, уходит напрямую в Meshy.
  Бэкенда/прокси нет (static-nobuild).
- **Просмотр:** GLB грузится в Three.js, OrbitControls (вращение/зум/сдвиг), автоповорот,
  каркас, сброс вида. **STL** — через `STLExporter`. Three.js — с CDN unpkg@0.160.0 (importmap).
- **Конструктор промпта:** чипсы объект/форма/стиль/печать + свободные поля → собирает
  английский промпт вживую; кнопка кладёт его в поле описания; поле negative → `negative_prompt`.

## 4. Открытые вопросы / что осталось

- **Оплата Meshy Pro** из РФ (нужна зарубежная карта) — пока не решено; без ключа Pro
  генерация не запустится.
- **CORS не проверен вживую** (нужен рабочий ключ). Если браузер заблокирует запрос к
  `api.meshy.ai` — понадобится прокси/бэкенд (при static-nobuild его нет). Просмотр и STL
  от CORS не зависят.
- **Runtime в браузере не прогнан** мной (в окружении нет headless-браузера) — проверена
  только выдача HTML и деплой. Клики стоит проверить вручную.
- Возможные доработки: автоперевод русского объекта в английский (словарик, без внешних
  сервисов); альтернатива — переезд на **Tripo3D** (бывает бесплатный API); режим «вьюер»
  с загрузкой своего GLB/STL.

## 5. Как отредактировать и опубликовать

Правки идут в репозитории `3d-print` (не в основном komfortist!). Клон рабочей копии:
```bash
# токен для доступа лежит в основном репозитории: /root/komfortist/.env.3dprint (в игноре)
git clone https://x-access-token:<GITHUB_TOKEN_3DPRINT>@github.com/alexey8080-create/3d-print.git
cd 3d-print
# ...правки в index.html...
git add . && git commit -m "что изменил" && git push origin main
```
Через ~1 минуту проверить прод:
```bash
curl -s https://alexey8080-create-3d-print-45dc.twc1.net/ | grep -o "<title>[^<]*</title>"
```

## 6. Доступы и секреты

- **GitHub PAT для 3d-print** — в основном репозитории `komfortist`, файл `.env.3dprint`
  (переменная `GITHUB_TOKEN_3DPRINT`; файл в `.gitignore` по маске `.env*`).
  ⚠️ Токен засветился в переписке — рекомендовано перевыпустить.
- **Timeweb API** — `kvartal/.env` → `TIMEWEB_API_TOKEN`. Полезные эндпоинты:
  `GET /api/v1/vcs-provider` (провайдеры), `GET /api/v1/vcs-provider/{id}` (репозитории),
  `POST /api/v1/apps` (создать app; поле ветки — `branch_name`; в `name`/`comment` нельзя «—»).
